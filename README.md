# Fantasy Hockey Analyzer — project site

Landing page for Fantasy Hockey Analyzer, a companion app for Yahoo Fantasy Hockey
leagues (true standings, weekly recaps, free-agent analysis).

Published via GitHub Pages from `index.html` at the repository root.

This repository contains the public project page only — not the application source.

Fantasy Hockey Analyzer is an independent project and is not affiliated with,
endorsed by, or sponsored by Yahoo Inc. or the National Hockey League.
